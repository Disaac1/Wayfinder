# Wayfinder Master Games List & Tier 1 Automation Specs

This document provides a complete registry of all **official Archipelago core games** and **community `.apworld` games**, detailing their current Wayfinder support tier, documentation links, and the specific technical requirements needed to achieve **Tier 1 (1-Click Auto-Launch)** support.

---

## Wayfinder Support Tiers Definition

- **Tier 1 (Full Direct Native Support)**: 1-Click "Start Game". Auto-downloads binaries, auto-syncs `host.yaml` / CLI args, auto-connects to AP server.
- **Tier 2 (Auto-Patch & Emulator / Clipboard Connect)**: 1-Click. Auto-verifies ROM, extracts `.ap*` patch, launches emulator, copies server address to clipboard.
- **Tier 3 (PC Mod / BepInEx Auto-Provisioning)**: 1-Click + Launch. Auto-provisions mod loader (SMAPI/BepInEx/Lovely), auto-writes connection config (`archipelago.json`).
- **Tier 4 (Custom `.apworld` Support)**: Drag & Drop `.apworld` into `/api/custom-worlds/upload`. Wayfinder dynamically generates UI options & multiworld support.
